### Quoi, Pourquoi, Comment ?

# Le Manifeste

- Arreter de stocker mentalement le nombre de paires de chaussettes de la demi-part fiscale
- Anticiper facilement les prochains achats pour le vestaire de l'enfant
- Soyons fous, permettre au mari de faire les achats de vetements
- Gerer les rotations de stock mieux que le Lidl de la rue de Rosny

# Les donnees de base ?

- Rentrer un vestiaire ideal par saison :
    - Manteau de pluie x 1 (Automne / Printemps)
    - Manteau chaud x 1 (Hiver)
    - Bottes de pluie x 1 (Automne / Printemps)
    - Baskets x 2 
    
- Rentrer les vetements qui existent :
    - Type 
    - Taille
    - Saison (Printemps / Ete / Automne / Hiver)
    - Specificite (Impermeable / Sport / Chaud / Maillot de bain)
    - Couleur
    - Marque
    - Occasion (Habille / Normal / Glandouille maison / On se depense)
    - Photo
    - Emplacement

- Rentrer les specs de l'enfant :
    - Genre (Optionnel : tu peux habiller ton enfant dans les collections filles et enfants :wink:)
    - Taille
    - Poids
    - Pointure
    - Age

# Comment mettre a jour ?

- Je mets a jour les infos du vestiaire :
    - Trop petit
    - Trop use

- J'upload les factures de mes nouveaux achats (pdf) : les donnees sont integrees automatiquement

# Que va faire l'appli ?

- Me demander si des vetements sont obsoletes : Ton enfant a 23 mois, ses vetements en 24 mois sont-ils encore a sa taille ?

- Anticiper les achats de vetements : nous sommes en fin d'annee, voici le vestaire ideal pour l'ete et une premiere selection.

- Faire de la veille sur certains articles : cet impermeable Jacadi pourrait etre utile et est actuellement a -40%.

- Permettre aux 2 parents de voir le contenu, les suggestions et les actions a anticiper sur la garde robe
